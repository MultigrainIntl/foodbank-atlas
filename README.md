# Food-Need Atlas

Neighborhood-level (census-tract) food-need maps for food banks, generated by one
config-driven pipeline from public U.S. Census data (via Census Reporter, keyless).

**Add a food bank:** drop a file in `config/`, e.g.
`{"name":"...","slug":"...","region_label":"...","county_fips":["06073"]}`,
then run the **Build Food-Need Atlas** workflow. Output is published to `docs/` (GitHub Pages).

No API keys, no paid services. Maps are illustrative — not a Feeding America product.
